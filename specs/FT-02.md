# FT-02 Input Berat & Notifikasi Min. Charge

Sumber PRD: Bagian 5 (BL-01), Bagian 6 (FT-02), Bagian 8 (AC-01), dan Bagian 9 (TC-01, TC-03)

## Tujuan
Pengguna dapat memasukkan estimasi berat cucian dalam kilogram dan langsung mengetahui apabila aturan minimum charge 3 kg diberlakukan.

## Alur
1. Pengguna mengetuk kolom input estimasi berat cucian (`kg`).
2. Pengguna mengetik atau menempel angka berat (menerima koma maupun titik sebagai pemisah desimal).
3. Jika nilai berat lebih dari `0` dan kurang dari `3`, sistem menetapkan berat ditagih menjadi `3 kg` dan memunculkan kotak informasi amber mengenai ketentuan minimum charge 3 kg.
4. Jika nilai berat `3 kg` atau lebih, berat ditagih sama dengan berat aktual dan notifikasi minimum charge tidak muncul.

## Data
- `STORE_INFO.minimum_charge_kg` (`3.0`)

## Aturan dan rumus
- Rumus BL-01: `beratDitagih = Math.max(STORE_INFO.minimum_charge_kg, beratAktual)` untuk `beratAktual > 0`.
- Jika input kosong atau `<= 0`, `beratDitagih` bernilai `0` pada tampilan kalkulasi dan tidak lolos validasi saat tombol kirim ditekan.
- Langkah input HTML `step="0.1"` dengan `inputMode="decimal"`.
- Pemisah desimal menerima `,` dan `.`, lalu ditampilkan kembali memakai koma tanpa nol di belakang (`1,8`, `3`, `4,5`).

## Input dan validasi
- Kolom `Estimasi Berat (kg)`: wajib diisi, angka positif (`> 0`).
- Jika kosong atau `<= 0` atau bukan angka valid saat tombol kirim ditekan: tampilkan error `"Masukkan berat cucian lebih dari 0 kg, contoh: 2,5."` dan pindahkan fokus ke kolom ini.

## Tampilan dan teks
- Judul bagian: `Estimasi Berat Cucian`
- Label input selalu terlihat: `Berat Cucian (kg)` dengan satuan `kg` dan contoh placeholder `Contoh: 2,5`.
- Notifikasi visual otomatis saat `0 < beratAktual < 3`: kotak status amber (`bg-amber-50 text-amber-800`) dengan ikon `Info` bertuliskan `Minimum charge 3 kg berlaku. Berat ditagih dihitung sebagai 3 kg.`

## Kasus uji
| ID | Input | Hasil yang diharapkan | Sumber |
| :--- | :--- | :--- | :--- |

| Kasus A | Berat `1,8` kg | Berat ditagih `3 kg`, notifikasi minimum charge 3 kg tampil | PRD BL-02 |
